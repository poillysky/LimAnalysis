# Metabase 可视化建图 / 表格（不写 SQL）

全程用 **新建 → 问题**（问号图标），不要点「SQL 查询」。

数据只选 **`v_eagle_rcvr_ads_3h`**（Whale 选 `v_whale_spkr_ads_3h`）。不要选 DWD、RAW，不要选带 `typed` / `defect_long` 的表。

视图已经是「数据最新 3 小时」。**不要**再点筛选里的「过去 3 小时」。

不良率必须是：**先把不良数加总、产量加总，再相除**。不要对「不良率」列点平均。

---

## 0. 每次都走这几步

1. 打开 Metabase（连接管理里的地址）。
2. 左上角 **新建 → 问题**。
3. 选 **原始数据** → 库 **lim_dwh** → 表 **`v_eagle_rcvr_ads_3h`**。
4. 会进入笔记本：上面一排是 **筛选 / 汇总 / 分组**。
5. 点右下角可视化图标：表格、数字、柱状图。
6. **可视化设置**（齿轮）里把比率列改成 **百分比**。
7. **保存** → **添加到仪表板**。

中文列名在点选列表里直接选即可，不用打引号。

---

## 1. 数字卡：自动外观总不良率

1. 新建问题，选中 `v_eagle_rcvr_ads_3h`。
2. **不要**点分组。
3. 点 **汇总**（Summarize）→ 最下面 **自定义表达式**。
4. 名称填 `总不良率`。
5. 公式栏点字段，拼成：

   `Sum([自动外观总不良数]) / Sum([自动外观总产量])`

   字段从左侧点选，不要手打列名。
6. 可视化选 **数字**。
7. 齿轮 → 该列 **百分比**，小数 2 位。
8. 保存为 `自动外观总不良率`。

注塑总不良率：公式里两个字段改成 `[注塑机总不良数]`、`[注塑机总产量]`。

良率：公式最前面加 `1 -`（同样是汇总表达式，不是平均）。

---

## 2. 柱状图：按线体 / 机台 / 模穴

以「各外观线体总不良率」为例：

1. 新建问题，选中 3h 视图。
2. **汇总** → **自定义表达式**，名称 `总不良率`：

   `Sum([自动外观总不良数]) / Sum([自动外观总产量])`

3. 点 **分组**（Group by）→ 选 **自动外观线体**。
4. 可视化选 **柱状图**。
5. 齿轮：

   - X 轴：自动外观线体
   - Y 轴：总不良率
   - 数字格式：**百分比**
6. 结果表头点 **总不良率** 做降序（柱从高到低）。
7. 保存。

换图只改分组字段：

| 图 | 分组点选 | 公式分子 | 公式分母 |
| --- | --- | --- | --- |
| 各机台外观不良率 | 机台 | 自动外观总不良数 | 自动外观总产量 |
| 各机台注塑不良率 | 机台 | 注塑机总不良数 | 注塑机总产量 |
| B5 · 各模穴 | 模穴 | B5合模线溢胶不良数 | 注塑机总产量 |
| B1 · 各模穴 | 模穴 | B1缺胶气泡不良数 | 注塑机总产量 |
| B2 · 各模穴 | 模穴 | B2凹坑不良数 | 注塑机总产量 |

外观单项（如外长直边）：分子点 `[外长直边不良数]`，分母仍是 `[自动外观总产量]`，分组按你要的线体或机台。

**复制一张图改口径：** 打开已保存问题 → 右上角 **复制** → 只改分组或公式里点选的字段 → 另存为新名字。

## 3. 表格

和柱状图同一条问题，右下角可视化改成 **表格** 即可。

建议同时加三列汇总（多次点「汇总」）：

1. 求和 → `[自动外观总产量]`，名称 `产量`
2. 求和 → `[自动外观总不良数]`，名称 `不良数`
3. 自定义表达式 `不良率`：`Sum([自动外观总不良数]) / Sum([自动外观总产量])`

再 **分组** → `机台`（或线体）。不良率列设百分比。点列名排序。

要看明细、不要汇总：选中表之后 **不要点汇总/分组**，可视化保持表格，需要时点 `hour` 列排序。

## 4. 多个不良项对比（仍不写 SQL）

宽表里每一项是一列，GUI **不能**做成「横轴 = 不良项名称」。做法：

**一张图里并排多根度量柱（推荐）**

1. 新建问题，选 3h 视图。
2. **分组** → `自动外观线体`（或不分组，看全厂）。
3. **汇总** 里为每一项各加一条自定义表达式，例如：

   - `外长直边`：`Sum([外长直边不良数]) / Sum([自动外观总产量])`
   - `正面硅胶`：`Sum([正面硅胶不良数]) / Sum([自动外观总产量])`
   - 其余外观项同样加

4. 可视化 **柱状图** → 齿轮里 Y 轴勾选这些表达式，格式百分比。
5. 得到：横轴线体，每种不良一项一种颜色的柱。

**不想挤在一张图：** 用第 2 节复制问题，每次只留一个不良项公式，标题写成该项名称。

不要去找 `defect_long` 表。

## 5. 窗口文字（数据实际时间）

GUI 数字卡不好拼「08:00 ～ 10:00」这种字符串。用表格即可：

1. 新建问题，选 3h 视图。
2. 汇总：`最小` → `hour`；再加一条 `最大` → `hour`。
3. 可视化 **表格**（或两个数字卡：最早 hour、最晚 hour）。
4. 放到画布顶栏，避免当成墙上时钟的「此刻近 3 小时」。

## 6. 保存进画布

1. **保存** → 名称与卡片标题一致。
2. 集合选该项目（EagleRcvr / WhaleSpkr 各一个）。
3. **添加到仪表板** → 已有「EagleRcvr 自动外观数据看板」，或新建。
4. 画布里拖大小：数字卡在上，柱图在下。
5. 仪表板 **保存**。
6. 本系统按仪表板 **名称里带项目名** 匹配。一项目默认只嵌 **一张** 画布：名字里同时有项目名和「自动外观」的优先；没有再退回只含 EagleRcvr 的那张。注塑画布要在本系统里看，名字里必须带「注塑」。

两张图共用同一批已保存问题，只是出现在不同画布上。缺窗口/总率时：打开已有问题 → **添加到仪表板** → 选对应那张画布。

**D. 嵌入**

每张仪表板打开一次：分享 / 嵌入 → 打开静态嵌入。本系统拉画布时也会尝试自动打开。

## 8. 点选时别踩的坑

| 现象 | 原因 | 点哪里改 |
| --- | --- | --- |
| 图是空的 | 又加了「过去 3 小时」 | 笔记本里删掉这条筛选 |
| 比率被摊平、和数字对不上 | 汇总选了「平均」不良率 | 改成自定义表达式：Sum 不良 / Sum 产量 |
| 显示此图表时出现问题 | 数据源还是 long/typed 旧表 | 问题左上角换成 `v_*_ads_3h` |
| 线体柱加起来不像总不良率 | 用了全厂产量当每根柱分母 | 先分组线体，再在组内 Sum/Sum |
| 找不到不良项当横轴 | 宽表没有「不良项」这一列 | 用第 4 节：多项公式并排，或一项一张图 |

口径（外观用外观产量、B5/B1/B2 用注塑产量）见 [10-dashboard-bi.md](./10-dashboard-bi.md) 第 4 节。
