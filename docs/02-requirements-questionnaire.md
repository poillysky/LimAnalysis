## A. 项目是什么

1. 这个系统正式名称、要解决的一句话问题是什么？（例如：把车间异常、不良、纠正措施收口到一个看板）
2. 第一期必须上线的模块有哪些？下面这些哪些保留、哪些删、还要加什么？
   - 工作台
   - 异常监控
   - 不良分析
   - FACA（请写全称：是 CAPA、8D、还是你们内部的 FACA 流程）
3. 明确 **不做** 的事：MES、排产、设备点检、SPC、追溯系统等，哪些绝对不在本项目里？
4. 使用场景：几家工厂、几条产线、几班倒？只内网还是也要外网？

## B. 谁用、怎么管

5. 角色有哪些？（操作员 / 班组长 / QE / 工艺 / 领导 / 系统管理员 …）每人主要干什么？
6. 登录方式：本系统账号，还是对接 AD / 企业微信 / SSO？要不要按钮级权限？
7. 数据权限：是否按工厂、车间、产线隔离？一个人能否看多条线？

## C. 两个 Postgres 怎么切

8. 两套库是：
   - 同一台 Postgres 上的两个 database，还是
   - 两台完全独立的实例？
9. **生产库**从哪来？
   - 本项目新建并写入车间数据，还是
   - 已有 MES / SCADA / QMS 库，本系统只读，或
   - 已有库 + 本系统补写部分表？
10. 本系统对生产库的权限：只读 / 可写 / 部分表可写？有没有「绝对不能改」的表？
11. **元数据库**你认为至少包括哪些？（可多选并补充）
    - 用户、角色、菜单、权限
    - 工厂 / 车间 / 产线 / 班次主数据
    - 不良代码、工序、设备、物料编码
    - 异常判定规则、阈值、告警推送配置
    - FACA 模板、流程节点、审批人
    - 报表/看板布局配置
    - 操作审计日志
12. 生产库里你预期有哪些事实数据？（批次、工单、过站、测试结果、不良明细、停机、参数曲线 …）有现成表结构或 Excel 样例吗？有的话下一步请提供。
13. 数据时效：实时（秒/分钟）、近实时、还是按班次/天批处理？数据保留多久？

## D. 三个业务模块各自指什么

14. **异常监控**：异常从哪来？人工报工、规则自动判定、还是外部系统推送？一条异常最少有哪些字段？
15. **不良分析**：分析到什么粒度（班次 / 产线 / 机台 / 料号 / 缺陷代码）？要哪些图（柏拉图、趋势、帕累托、漏斗）？
16. **FACA**：流程步骤、谁建单、谁闭环、是否必须关联异常或不良批次？状态机有哪些状态？
17. 工作台第一屏必须看到哪几个数字/图表？

20. 部署：纯内网一台服务器，还是前后端/库分开？有没有等保或客户审计要求？
